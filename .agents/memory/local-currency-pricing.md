---
name: Local currency pricing
description: User's repeated requirement for country-specific currencies against USD
---
Use a native currency for each user: each country and its currency against the standard dollar.

**Why:** The user repeated this instruction after the founder dashboard displayed mixed local currencies as dollars.

**How to apply:** Keep USD as the base price and convert customer prices to their country currency. Preserve the actual transaction currency in receipts and records. Never add different currencies into a dollar total without conversion, or revalue historical payments using today's rates.
